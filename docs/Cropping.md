# 取景器裁剪简易说明

适用于[专辑取景框（AlbumFrame）](AlbumFrame.md)与[魔法取景框（MagicFrame）](MagicFrame.md)。两款取景器都在原始画面中央放置一块成片画板，截图后沿画板边界裁剪，保留其中的画面、内部留边，以及 MagicFrame 中越过内部窗口的人物部位。

## 成片范围看“画板比例”

“画板比例”决定最终成片的宽高比。画板始终居中，并按所选比例在原始画面内尽量铺满。

- **画板**：最终要保留的完整矩形，包括内部留边。
- **内部窗口**：画板内显示照片或场景的区域，其比例、大小和位置用于调整构图，不改变成片尺寸。
- **画板外区域**：完整截图中画板四周的遮罩，裁剪后去除。

例如，原始截图为 **2560 × 1440**，画板比例为 **1:1**，成片就是 **1440 × 1440**。即使内部窗口选了 2:3、缩小到 80% 或移到一侧，也仍然裁剪这块正方形画板。画板比例改为 9:16 时，成片才变为 810 × 1440。

AlbumFrame 默认画板比例为 1:1，MagicFrame 默认为 9:16；更改比例后，按当前选择查表。AlbumFrame 的“拍立得留白”只调整内部布局：画板仍为 1:1 时，成片仍为正方形；画板选择“经典拍立得（88:107）”时，才按 88:107 裁剪。

## 三步裁剪

1. 打开保存下来的原始截图，查看文件的实际宽度和高度。下表中的“2K”指 **2560 × 1440**，“4K”指 **3840 × 2160**；请按文件尺寸选择表格。
2. 确认拍摄时取景器的“画板比例”，查找对应的成片尺寸和裁剪坐标。
3. 在图片编辑器的裁剪工具中，按像素输入左上角 `X`、`Y` 和裁剪宽、高，另存成片。操作应保留原有像素，不缩放图片。

坐标从原始截图左上角 `(0, 0)` 开始，`X` 向右增加，`Y` 向下增加。例如，2560 × 1440 的截图配 1:1 画板，输入 **X = 560、Y = 0、宽 = 1440、高 = 1440** 即可。

优先使用支持按像素输入选框大小和位置的裁剪工具。只按固定比例居中框选时，取整可能与下表相差一像素；按表中整数尺寸与坐标输入，可精确保留画板边界。

## 常用成片尺寸与坐标

1:1、4:3、3:4、16:9、9:16 是两款取景器共有的画板预设。2:3 是 MagicFrame 的画板预设，88:107 是 AlbumFrame 的画板预设；另一款取景器可通过“自定义画板宽：高”设置同样的比例。自定义时，2:3 输入 `2`、`3`；88:107 输入等比例的 `8.8`、`10.7`，使两个数值都处于控件范围内。

## 其他分辨率与自定义比例

超宽屏、竖屏或其他截图尺寸使用同一条规则：按画板比例在原图内尽量铺满，再居中。设原始截图为 `W × H`，画板宽高比为 `r = 画板宽 / 画板高`，计算如下；`floor` 表示向下取整。

```text
unroundedWidth = min(W, H * r)
width  = max(floor(unroundedWidth + 0.5), 1)
height = max(floor(unroundedWidth / r + 0.5), 1)
X = floor((W - width) / 2)
Y = floor((H - height) / 2)
```

在裁剪工具中输入 `X`、`Y`、`width`、`height`。若工具需要右、下边界，对应范围为 `[X, X + width) × [Y, Y + height)`，右、下边界不包含在保留范围内；若填写最后一个保留像素的坐标，则右、下坐标分别再减 1。高度计算使用尚未取整的 `unroundedWidth`，与两款着色器的画板计算顺序一致。

内部留边、窗口背景与人物穿框都包含在最终画板内。画板外颜色与内部留边颜色可能相同，按上述尺寸与坐标确定裁剪范围。当前截图文件仍保留完整分辨率，成片需要手动裁剪；[按画板自动另存裁图](FrameToolsRequirements.md)属于后续规划。
