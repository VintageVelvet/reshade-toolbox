# 专辑取景框 · 第一版

`Shaders/AlbumFrame.fx` 为独立 ReShade 着色器，使用现有 `ReShade.fxh`。默认显示居中、铺满屏幕短边的正方形画板，画板外纯黑。通过游戏镜头调整人物大小和位置。

## 安装与使用

1. 将 `Shaders/AlbumFrame.fx` 放到 ReShade 的着色器搜索目录下。安装后可与本仓库其他着色器分别启用。
2. 在游戏内重新加载效果，搜索并启用 `Album Frame - 专辑取景框`（技术名 `AlbumFrame`）。
3. 将效果放到效果顺序末尾，使其他调色、模糊效果先执行，最后绘制遮罩和边框。
4. 默认画板为 1:1；可选横竖比例或自定义宽高数值。画板始终居中、在屏幕内最大化。
5. 需要留白时打开“启用内部留边”。选择窗口比例，再调整大小、位置和颜色；“自由宽高”模式可分别调整两个方向。
6. 保存当前 ReShade 预设可记录参数。拍摄时使用包含效果的截图；参考线默认关闭，开启后也会进入截图。

此效果只遮罩画面：窗口内保留原位置采样，不改变镜头、画面缩放、清晰度或场景深度。截图仍是游戏原分辨率，自动裁切尚未实现。

## 参考布局

以下均使用 1:1 画板，窗口位置居中。

| 布局 | 内部留边 | 窗口比例 | 窗口大小 | 边框颜色 |
|---|---|---|---|---|
| 满版封面 | 关闭 | — | — | — |
| 横幅与上下宽边 | 开启 | 16:9 | 100% | 白色或自选 |
| 横幅与四周留白 | 开启 | 16:9 | 90% | 白色 |
| 上下窄白边 | 开启 | 5:4 | 100% | 白色 |
| 竖图与左右留白 | 开启 | 2:3 或 5:7 | 100% | 白色 |

## 确定的裁切范围

裁切整张画板，保留内部边框；不要通过检测黑色判断边界。设截图尺寸为 `W × H`，画板宽高比为 `r`，计算顺序与着色器相同：

```text
unroundedWidth = min(W, H * r)
width  = max(floor(unroundedWidth + 0.5), 1)
height = max(floor(unroundedWidth / r + 0.5), 1)
x = floor((W - width) / 2)
y = floor((H - height) / 2)
裁切矩形为 [x, x + width) × [y, y + height)
```

3840 × 2160 截图的默认裁切为 `(840, 0, 2160, 2160)`；2560 × 1440 为 `(560, 0, 1440, 1440)`。奇数尺寸或不能整除的比例会有不足一像素的取整误差，中心两侧边距最多相差一像素。

## 实现与验证范围

检查过外部库的 SweetFX/Border.fx、OtisFX/MagicBorder.fx 和 Fubax/AspectRatio.fx：它们分别提供单层边框、深度四角边框或画面比例变换。此版本独立实现嵌套矩形遮罩，未复制这些着色器的实现；直接复用运行环境的 ReShade.fxh 和全屏顶点着色器。

几何验证覆盖横屏、竖屏、超宽屏、奇数尺寸及 2K/4K；已通过 2560 × 1440 与 3840 × 2160 的 ReShade FX / DXBC SM5 顶点及像素编译，无错误或警告；游戏内显示和截图仍待实际确认。详见 [验证记录](VALIDATION.md)。若后续效果修改颜色或进行空间采样，应将本效果移到它们之后。
