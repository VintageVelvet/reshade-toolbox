# 版本记录

## 2026-10-06 — CopyrightAdaptive 复制安装

- 提供复制安装压缩包，顶层包含 `CopyrightAdaptive.fx` 和 `CopyrightAdaptive/` 私有目录，将两者解压到原 `Copyright.fx` 所在目录即可重新加载使用。
- 私有样式头文件从 FX 旁边的相对目录读取，PNG 复用原安装中有效的纹理搜索目录；随包菜单采用参考素材对应的 45 / 63 / 12 项固定列表。
- 主使用说明集中介绍解压、启用和 1440 基准；预设迁移、自定义 PNG 及素材集合不同时使用的可选工具放入技术附录。
- 日常使用按独立的末尾水印效果说明：启用、排序、选择款式和调整位置；移除专门保存预设及再次重新加载的必需步骤，明确新旧效果、独立样式表与共享 PNG 的关系。

- 增加维护者打包工具，从指定 Git 提交读取五个分发文件，生成可直接解压的扁平压缩包。

## 2026-10-05 — CopyrightAdaptive 安装流程简化

- 新增 `tools/Install-CopyrightAdaptive.ps1`，只需提供游戏目录即可读取 `ReShade.ini` 中的搜索路径，按当前 PNG 生成可用款式并安装模块；不修改全局 `ReShade.ini`。
- 支持可选的 `-Preset`，读取相对于游戏目录的预设路径并另存迁移结果。
- 使用说明集中介绍安装、启用和 1440 基准；旧编号、菜单宏、缺图项、自定义 PNG 和样式生成说明移入技术附录，补充各类相对路径的基准。

- 修复迁移输入、输出和同步输出的相对路径解析，使其跟随 PowerShell 当前目录；样式生成支持多个纹理搜索根与递归范围。

## 2026-10-05 — CopyrightAdaptive 分辨率适配

- 新增独立版权标志效果 `CopyrightAdaptive`，复用现有安装的 PNG，提供按基准画面高度缩放及固定比例位置。
- 保留原 Copyright 的位置、缩放、颜色、阴影和混合设置；旧款式编号继续兼容，新菜单使用独立的紧凑序号。
- 移除参考安装缺图的 AUR 10 / 29 / 47 和 XIV 15 / 16，默认菜单保留 45 / 63 / 12 项。旧预设引用移除项时回退到可用款式。
- 保留手动 Custom 47；显式图片与固定宽高分别控制素材和各轴的分辨率缩放，避免默认画面尺寸再次放大。
- 增加 `tools/Convert-CopyrightAdaptivePreset.ps1` 和 `tools/Sync-CopyrightAdaptiveStyles.ps1`，用于另存迁移与按现有素材生成列表。
- 增加 `docs/CopyrightAdaptive.md`，补充来源、许可与真实编译验证范围；仓库不包含 PNG、依赖头文件或本机诊断清单。

## 2026-10-05 — 统一画板外默认色

- 专辑取景框的画板外颜色默认改为深灰，与 MagicFrame 相同；内部留边颜色继续独立设置。
- 已保存预设中的颜色继续沿用，可单独重置“画板外颜色”使用新默认值。

## 2026-10-05 — MagicFrame 0.1

- 新增独立魔法取景框，默认居中 9:16 画板与 80% 内部窗口，支持预设 / 自定义比例、大小和位置。
- 根据统一窗口深度保留近景，让人物越过内部窗口覆盖留边；提供原场景 / 纯色窗口背景及独立的画板外、留边和窗口颜色。
- 提供深度过渡、前景选区和深度预览，以及独立的 MagicFrame_Guides 构图辅助；ReShade 自身截图可隐藏辅助线。
- 补充横屏截图的裁切坐标、效果排序与拍摄流程说明；编译和源码检查记录见 [VALIDATION.md](VALIDATION.md#magicframe-01--2026-10-05)。

## 2026-10-03 — DR DLSS 手动模块 0.1.2.0

- 新增 DailyRoutines 自定义模块，适配 DR 2.2.2.0；提供模型 / 默认挡位、三个手动按钮、高级刷新和快捷命令。
- 提供游戏默认、K、L、M，按 DLSS 文件版本过滤；选择框与单行路径框按内容测量宽度，调整间距与界面描述。
- 每秒读取配置倍率，显示游戏输出尺寸及按配置估算的 DLSS 输入尺寸；读取不覆盖待写入选择。
- 配置保存与下次启动加载列为模块验证项。

- 新增画板外颜色，与内部边框颜色分别控制。

- 记录标准 FX 面板限制与旧自定义预设的迁移方式。

## 2026-09-29 — 专辑构图辅助
