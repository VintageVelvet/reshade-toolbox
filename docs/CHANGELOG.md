# 版本记录

## 2026-10-05 — 统一画板外默认色

- 专辑取景框的画板外颜色默认改为深灰，与 MagicFrame 相同；内部留边颜色继续独立设置。
- 已保存预设中的颜色继续沿用，可单独重置“画板外颜色”使用新默认值。

## 2026-10-05 — MagicFrame 0.1

- 新增独立魔法取景框，默认居中 9:16 画板与 80% 内部窗口，支持预设 / 自定义比例、大小和位置。
- 根据统一窗口深度保留近景，让人物越过内部窗口覆盖留边；提供原场景 / 纯色窗口背景及独立的画板外、留边和窗口颜色。
- 提供深度过渡、前景选区和深度预览，以及独立的 MagicFrame_Guides 构图辅助；ReShade 自身截图可隐藏辅助线。
- 补充横屏截图的裁切坐标、效果排序与拍摄流程说明；编译和源码检查记录见 [VALIDATION.md](VALIDATION.md#magicframe-01--2026-10-05)。

## 2026-10-03 — DR DLSS 手动模块 0.1.2.0

- 新增 DailyRoutines 自定义模块，适配 DR 2.2.2.0；提供模型 / 默认挡位、三个手动按钮、高级刷新和快捷命令。
- 提供游戏默认、K、L、M，按 DLSS 文件版本过滤；选择框与单行路径框按内容测量宽度，调整间距与界面描述。
- 每秒读取配置倍率，显示游戏输出尺寸及按配置估算的 DLSS 输入尺寸；读取不覆盖待写入选择。
- 配置保存与下次启动加载列为模块验证项。

## 2026-09-29 — 解耦画板与留边

- 88:107 只负责画板比例；拍立得留白移入独立内部布局，服从留边开关，支持大小与位置。
- 新增画板外颜色，与内部边框颜色分别控制。

## 2026-09-29 — 经典拍立得布局

- 新增 88:107 画板与 79:79 成像区的一键布局，底部加宽留白。
- 构图线自动适配成像区；保留普通画板设置，切换后恢复。

## 2026-09-29 — 自定义布局试用版

- 保留全部固定比例，合并自定义与自由宽高入口；自定义统一使用画板百分比宽高。
- 移除重复的自定义比例输入，明确预设缩放与自定义宽高的适用范围。
- 记录标准 FX 面板限制与旧自定义预设的迁移方式。

## 2026-09-29 — 专辑构图辅助

- 将画板轮廓线替换为 12 种构图模式，可基于内部窗口或整个画板绘制。
- 构图线跟随窗口位置和大小，默认黑色、半线宽 1 像素。
- 独立构图效果支持 ReShade 截图隐藏，保留画板遮罩。

## LandscapeComposition 默认配置调整

- 默认构图线改为纯黑、100% 不透明度，半线宽改为 1.00 像素。

## 2026-09-28 — AlbumFrame 0.1

- 新增专辑取景框：居中最大化画板、预设与自定义比例、画板外纯黑遮罩。
- 提供可选内部留边、窗口比例/自由宽高、大小、位置、底色与边界参考线。
- 框内保留原坐标采样，不使用场景深度；完整截图保留遮罩，记录确定的裁切范围。
- 添加 `Shaders/AlbumFrame.fx` 和使用说明 `docs/AlbumFrame.md`。
