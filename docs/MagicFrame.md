# 魔法取景框

`Shaders/MagicFrame.fx` 为独立 ReShade 着色器。默认在横屏画面中央放置 9:16 竖版画板，内部窗口宽、高各占画板的 80%，周围为黑色留边。通过场景深度保留近景，让帽子、手臂、衣袖等部位越过内部窗口，覆盖留边。截图后沿整块画板裁切，即可得到竖图。

## 安装与第一次拍摄

1. 将 `Shaders/MagicFrame.fx` 放到 ReShade 的着色器搜索目录，确保目录中有标准 `ReShade.fxh`，然后在游戏内重新加载效果。
2. 搜索并启用 `Magic Frame - 魔法取景框`（技术名 `MagicFrame`）。排序为：调色、景深等画面效果 → `MagicFrame` → `MagicFrame_Guides`。使用时关闭 AlbumFrame 和旧 MagicBorder 的遮罩，避免先前的边框盖掉需要保留的人物颜色。
3. 先保持默认的“原场景”窗口背景。用游戏镜头将人物放到竖版画板中，让帽子或手臂越过内部窗口的边缘。
4. 调整“窗口深度”，直到人物需要保留的部位完整显示，周围没有多余的近景物体。可切到“前景选区”查看深度选出的区域，再用“深度预览”检查场景深度。
5. 切回“正常画面”显示模式后截图。需要纯色人物海报时，再将窗口背景切换为“纯色”并调整颜色。
6. 截图仍为游戏原分辨率；按下文坐标裁切画板，保留内部留边与穿框人物。保存 ReShade 预设可记录当前参数。

“窗口深度”可以理解为人物身后的一块虚拟挡板：比挡板靠近镜头的像素会显示在留边前面。默认值为 10.0，使用 ReShade 线性深度乘以 1000 的相对数值，范围为 0–1000，不代表米数。数值增大时，通常会保留更多距离较远的物体；调节时以“前景选区”显示为准。

“前景选区”以绿色显示整块画板内的候选近景，关闭穿框后也能继续查看。“深度预览”用近黑、远白表示深度，当前窗口深度对应中灰；调整窗口深度也会改变预览明暗。两者属于主效果的显示模式，会进入截图，拍摄前请切回“正常画面”。若这些模式无法区分人物与背景，先检查 ReShade 的深度缓冲设置和当前场景是否提供可用深度。

## 画板、内部窗口与颜色

画板决定最终成片范围，始终居中并在屏幕内最大化。人物可以越过内部窗口，但到画板边缘时仍会被裁掉。

| 控件 | 作用 |
|---|---|
| 画板比例 | 选择 1:1、4:3、3:4、16:9、9:16、2:3 或自定义宽高比，默认 9:16 |
| 启用内部留边 | 默认开启；关闭后内部窗口铺满画板，穿框所覆盖的留边区域也随之消失 |
| 窗口形状 | 跟随画板、1:1、16:9、5:4、2:3、5:7 或自定义 |
| 预设窗口大小 | 跟随画板与固定比例窗口在画板内等比缩放，默认 80% |
| 自定义窗口：宽度 / 高度 | 自定义窗口分别占画板宽、高的百分比 |
| 窗口位置 | 水平、垂直分别调整；0 居中，-1 贴左 / 上，1 贴右 / 下 |
| 框内背景 | 原场景或纯色，默认保留原场景 |
| 画板外颜色 | 默认深灰，标出裁切后舍弃的区域 |
| 留边颜色 | 默认黑色，保留在最终照片中 |
| 纯色背景颜色 | 默认粉色，仅在纯色窗口背景下使用 |

例如默认 9:16 画板配合“跟随画板”、80% 窗口大小，左右与上下分别留出画板对应尺寸的 10%。选择自定义后，宽度 80%、高度 65% 可让上下留边更宽；窗口位置在当前可移动空间内调整。

窗口内读取画面原位置的颜色，不缩放或移动场景。人物大小和位置仍通过游戏镜头调整。三种颜色独立控制，画板外区域会出现在完整截图中，裁切后去除。

## 深度穿框

“允许人物越过窗口”默认开启，控制留边区域是否恢复近景。关闭后，留边会遮住所有物体；纯色窗口内仍按深度保留人物。

- **原场景背景**：窗口内保留原画面；窗口外的留边遮住远景，近景人物继续显示。
- **纯色背景**：窗口内的远景替换为所选颜色，近景仍保留原画面；窗口外的远景使用留边颜色，近景仍可穿框。
- **深度过渡宽度**：默认 0，使用明确的深度分界。需要缓和阈值附近的颜色变化时可小幅增加；过渡范围较大会让处于该深度范围的物体半透明。

该效果按距离判断前景，人物旁边同样靠近镜头的墙面、道具也会穿框。调深度或换机位可以排除这些物体。头发、半透明衣料是否完整进入深度图，需要在游戏内用选区预览检查。

## 构图辅助与截图

同文件提供独立效果 `Magic Frame Guides - 魔法取景构图线`（技术名 `MagicFrame_Guides`），安装后默认不启用。需要时开启，排在 `MagicFrame` 后面。模式为关闭、中心线、三等分、窗口轮廓、画板轮廓，默认三等分。

“中心 / 三等分参考区域”默认内部窗口，也可以选择整个画板；轮廓模式直接标出窗口或最终裁切画板。辅助线默认白色、70% 不透明度、总宽 1 像素，颜色、透明度与宽度均可调整，宽度设为 0 时隐藏所有线条。

辅助效果使用 `enabled_in_screenshot = false`，在支持该功能的 ReShade 5.2+ 自身截图中隐藏构图线，保留主效果绘制的画板与留边。游戏截图、系统截图和录屏会包含当前可见的辅助线，拍摄前可关闭 `MagicFrame_Guides`。

## 确定的裁切范围

裁切整张画板，保留内部留边和穿框人物。画板外颜色与留边颜色可能相同，请按坐标裁切。设截图尺寸为 `W × H`，画板宽高比为 `r`，计算顺序与 AlbumFrame 相同：

```text
unroundedWidth = min(W, H * r)
width  = max(floor(unroundedWidth + 0.5), 1)
height = max(floor(unroundedWidth / r + 0.5), 1)
x = floor((W - width) / 2)
y = floor((H - height) / 2)
裁切矩形为 [x, x + width) × [y, y + height)
```

| 横屏截图尺寸 | 默认 9:16 裁切尺寸 | 左上角坐标 `(x, y)` |
|---|---|---|
| 3840 × 2160 | 1215 × 2160 | `(1312, 0)` |
| 2560 × 1440 | 810 × 1440 | `(875, 0)` |

奇数尺寸或不能整除的比例会有不足一像素的取整误差，中心两侧边距最多相差一像素。效果不自动裁图，也不增加竖图分辨率。

## 实现与验证范围

MagicFrame 使用运行环境的 `ReShade.fxh` 获取当前颜色与线性深度，一次合成画板外遮罩、内部背景、留边和穿框前景。画板与窗口采用矩形布局，所有前景使用同一个窗口深度阈值，并提供基础构图辅助。

已完成源代码审查与 ReShade FX / DXBC SM5 编译，结果见[验证记录](VALIDATION.md)。具体游戏中的人物轮廓、效果排序和截图行为需按上述拍摄步骤检查。
