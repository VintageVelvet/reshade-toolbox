# 取景工具扩展需求

更新日期：2026-10-05。

状态：规划中，尚未实现。

本文说明 MagicFrame 与 AlbumFrame 的两项扩展需求：自定义宽高继承固定模板，以及按成片画板自动另存裁图。两项功能用于减少横屏取竖幅时的参数调整和手动裁切操作；预期交互与验收条件见下文。

现有着色器仍使用各自保存的模板与自定义参数，截图后需手动裁切。操作方法见[魔法取景框](MagicFrame.md)与[专辑取景框](AlbumFrame.md)。

## 1. 自定义继承上一次固定模板

适用于 MagicFrame 的内部窗口。保留现有固定模板和自定义入口，自定义宽高沿用最近选用的固定模板尺寸，便于微调。

- 选择固定模板时，将窗口的实际宽、高换算后填入自定义宽高框。
- 在固定模式下修改模板大小或画板比例等相关参数时，继续同步自定义宽高。
- 自定义宽高仅在自定义模式下影响画面；固定模式下显示这些数值，方便查看和准备修改。
- 在固定模式下手动修改自定义宽高后，切到自定义应直接使用这些编辑值。切换动作本身不再覆盖数值。
- 再选其他固定模板时，以新模板更新自定义数值，供下一次微调。
- 加载已保存的自定义预设时，恢复保存的宽高；位置、颜色及其他独立参数继续按各自设置生效。

例如，9:16 画板中的 1:1 窗口设为 80% 大小时，自定义宽高应约为画板的 80% / 45%。切到自定义后仍保持同一正方形，再分别调整宽、高。

验收时检查固定模板、大小和画板变化后的数值同步；未手动修改自定义宽高时，切换后保持窗口边界；手动编辑后，切换采用编辑值。另检查已保存预设的恢复。

## 2. 按成片画板自动另存裁图

适用于 MagicFrame 和 AlbumFrame。拍摄时记录当前画板范围，保存完整横屏截图，同时另存一张裁好的成片。

- 裁切范围为外部成片画板，包含内部留边和人物越过内部窗口的部分。
- 原图保留，裁图另存；画板外区域从裁图中去除。
- 根据拍摄时的截图尺寸和画板比例计算边界，沿用着色器的像素取整规则，避免通过背景颜色猜测边界。
- 裁图使用拍摄当时的参数。连拍或拍完立即修改比例时，各张图片仍对应各自拍摄时的画板。
- 正常成片隐藏取景器的构图辅助线。

例如，2560 × 1440 截图中的 9:16 画板裁为 810 × 1440，左上角坐标为 `(875, 0)`。两款着色器的裁切规则见[魔法取景框](MagicFrame.md#确定的裁切范围)和[专辑取景框](AlbumFrame.md#确定的裁切范围)。

验收时检查裁图尺寸、边缘、留边和穿框人物是否完整，以及连拍、参数变化、中文保存路径和原图保留情况。

## 实现候选与兼容范围

候选方案使用 C++ ReShade Add-on（编译为 `.addon64`）同步面板参数，并使用 Windows 自带图像组件裁切、另存 PNG。普通 FX 着色器无法直接写回面板中的其他参数。

候选兼容基线为 ReShade **6.6.1**，对应 SDK 和完整 Add-on 构建支持待核对，具体兼容范围需经实现与测试确定。

自动裁图初期可覆盖普通 SDR 截图和 PNG 输出。扩展专用拍摄快捷键便于关联截图与画板参数，复用现有 ReShade 截图键则需要处理不同截图类型和连拍关联；入口方式尚未确定。游戏自带截图的接入另行评估。
